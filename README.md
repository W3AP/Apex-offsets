##  Features

###  Aimbot
- **Hitbox-based aiming** — Head / Neck / UpperChest / Body 
- **FOV cone**
- **Smoothing curve**
- **Reaction delay** — humanized latency
- **Rate cap** 
- **Overshoot %**  
- **Jitter %** 
- **Miss radius**
- **ADS-only filter** — (`m_bZooming`)
- **Visible-only filter** — `lastVisibleTime`
- **Knocked-player exclusion** — 
- **Aim prediction** for projectile weapons (Bocek / Sentinel / Longbow / Charge Rifle)
- **Predicted-point visualization**

###  Triggerbot
- Hotkey-hold activation (default: mouse-forward)
- FOV cone gate
- Configurable click hold + interval
- Reaction delay
- Visible-only filter
- Optional FOV visualization

###  Box ESP
- **3D bounding boxes** 
- **Corner-style** 
- **Black outline** 
- **Distance** 
- **Vertical HP bar** left, **Shield bar** right, color-coded
- **Player name** + Team ID 
- **Champion name** 
- **Visible / Hidden color** (green / red)
- **"DOWN" marker** 
- **Max-distance filter**

###  Skeleton ESP
- Full bone-chain skeleton (Head → Neck → Chest → Pelvis + Arms + Legs)
- Vis-check with separate colors for visible / hidden bones
- Configurable line thickness
- Also renders on Firing Range dummies

###  Loot ESP
- Item name resolved from **model-path** — no hardcoded IDs
- **Rarity colors** — Common / Rare / Epic / Legendary / Heirloom
- **Min-rarity slider** 
- **Category toggles** — Weapons · Meds · Ammo · Attachments · Armor · Misc
- **Per-item right-click filter** — turn individual items on/off
- **Death-box** 
- **Max-distance filter**
- Distance display optional per item

###  Dummy ESP
- Firing Range training dummies detected + rendered
- Own dedicated color
- Full skeleton support
- Aim-target for aimbot tuning

###  Radar
- Circular mini-radar
- **Rotate with player yaw** or **North-up** mode
- Range 
- Configurable dot size

###  Spectator List
- Live panel 
- Vertically centered on the right

###  Battle Mode
- Hotkey-toggle 
- On-screen **BATTLE MODE** indicator
